# TryOS

## Development Command Arguments
1. /DevMode - Enables Development Features and logging.
2. /ShowConsole - Shows a fullscreen console window that can be used to execute commands.
3. /ShowCommanderOnContextMenu - Shows a Commander button on the ShellGUI Context Menu. (1.1+)
4. /VS_Debug - Makes Debug Manager send it's log to Visual Studio's Debug Output. (Debug.WriteLine())
5. /TurnOff_VerifyedShellOnly - Turns off safely code check on ShellCode. It's not recommended to turn off safely checks.
6. /DisableSandboxingForCommander - This disables Sandboxing in Commander.
